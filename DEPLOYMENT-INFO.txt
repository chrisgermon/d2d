=== Management Commands ===

View live logs:
  az containerapp logs show --name d2d-app-vnet --resource-group d2d-rg --follow

Update the app (after code changes):
  cd /home/claudeagent/d2d
  ./update-d2d.sh

Manual update:
  cd /home/claudeagent/d2d
  az acr build --registry d2dacr9129522 --image d2d:latest . --platform linux
  az containerapp update --name d2d-app-vnet --resource-group d2d-rg --image d2dacr9129522.azurecr.io/d2d:latest

Restart container:
  az containerapp revision restart --name d2d-app-vnet --resource-group d2d-rg

Scale the app:
  az containerapp update --name d2d-app-vnet --resource-group d2d-rg --min-replicas 1 --max-replicas 5

Check network configuration:
  az containerapp env show --name d2d-env-vnet --resource-group d2d-rg --query vnetConfiguration

List all resources:
  az resource list --resource-group d2d-rg -o table

Delete everything:
  az group delete --name d2d-rg --yes
  # Note: This will NOT delete the VNet (it's in rg-migration-vpn)

=== Troubleshooting ===

Connection fails to PACS:
  1. Verify PACS allows 10.200.2.0/23 subnet
  2. Check VPN/ExpressRoute is active
  3. Test from another machine on 10.200.x.x network
  4. Check firewall rules
  5. View container logs for errors

View detailed logs:
  az containerapp logs show --name d2d-app-vnet --resource-group d2d-rg --follow

Check if container is running:
  az containerapp show --name d2d-app-vnet --resource-group d2d-rg --query properties.runningStatus -o tsv

Test from container (if needed):
  az containerapp exec --name d2d-app-vnet --resource-group d2d-rg --command "/bin/bash"
